## Sections

| Section | What it shows |
|---|---|
| Home | Intro, typing effect, Hire Me / Download CV / View Resume / GitHub buttons |
| About | Introduction, career objective, interests and values |
| Education | Timeline of BSc, HSC and SSC |
| Skills | Programming, web development, database and tools |
| Projects | Project cards (more projects will be added) |
| More Info | Languages and hobbies |
| Gallery | Photos with a full-screen lightbox |
| Contact | Email, phone, location and social links |

## Features

- Fully responsive (mobile, tablet, desktop)
- Sticky navbar with mobile menu and active-link highlight
- Scroll progress bar and back-to-top button
- Scroll reveal animations
- Resume opens in a pop-up with a download button
- Gallery lightbox with arrows, keyboard keys and swipe support
- Tap to copy email and phone number
- Supports the device's reduced-motion setting

## Tech Stack

- HTML5
- Tailwind CSS (CDN)
- JavaScript (vanilla)
- Font Awesome 6.4
- Google Fonts (Poppins)

> The site loads Tailwind, Font Awesome and the font from CDNs, so internet is needed to see it properly.

## Getting Started

1. Clone the repository

   ```bash
   git clone https://github.com/Lucifer6x/YOUR-REPO-NAME.git
   ```

2. Go into the folder

   ```bash
   cd YOUR-REPO-NAME
   ```

3. Open `index.html` in your browser (or use the VS Code **Live Server** extension).

## How to Customize

- **Change CV:** search `.pdf` in `index.html` and replace the file name in all 3 places. The name must match exactly.
- **Add a project:** search `PROJECT CARD`, copy the whole card and paste it above `ADD NEW PROJECT CARDS HERE`.
- **Change GitHub link:** search `github.com/Lucifer6x` and replace it everywhere.
- **Change photos:** replace the image files or edit the `src` of the `<img>` tags.

## Deploy with GitHub Pages

1. Push the project to a GitHub repository.
2. Go to **Settings > Pages**.
3. Under **Branch**, choose `main` and `/ (root)`, then click **Save**.
4. Wait a minute and your site will be live.

> GitHub Pages is case-sensitive, so file names in the code must match exactly. It is safer to remove spaces from file names (for example `Abdulla-Al-Asif-CV.pdf`).
